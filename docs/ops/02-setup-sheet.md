# 구글 시트 생성 및 탭 구성

## 새 스프레드시트 생성
1. https://sheets.new 접속 (또는 Google Drive → 새로 만들기 → Google 스프레드시트).
2. 이름을 정한다. 예: `경건생활점검 데이터`.
3. URL의 `/d/<ID>/edit` 부분에서 시트 ID를 메모해 둔다. 이후 GAS Script Properties(`03-deploy-gas.md`)에 입력한다.

## 탭 2개 만들기

기본으로 생긴 "시트1"의 이름을 `MEMBERS`로 바꾸고, 탭을 하나 더 추가해 `RECORDS`로 이름을 바꾼다. 탭 이름은 대소문자까지 정확히 일치해야 한다.

### MEMBERS

1행(헤더)에 다음을 정확히 입력한다 (`docs/specs/2026-07-18-api-contract.md` §2 기준, 오타 시 앱이 오동작한다):

```
email | 이름 | role | 파트 | active
```

- **email**: 로그인에 사용할 구글 계정 이메일. 이 값으로 학생/교사를 식별하므로 정확히 입력.
- **이름**: 화면에 표시될 이름.
- **role**: `student` 또는 `teacher` 중 하나. `admin`도 허용되지만 v1에서는 `teacher`와 동일하게 취급된다.
- **파트**: 찬양팀 파트(보컬, 건반, 드럼 등). 자유 텍스트, 학생 행에만 채우면 된다.
- **active**: 비워두면 활성으로 간주한다. 비활성으로 처리하려면 `FALSE`, `NO`, `0`, `N` 중 하나를 입력한다 (대소문자 무관). 그 외 값은 모두 활성 취급.

2행부터 학생·교사 데이터를 입력한다. 예:

| email | 이름 | role | 파트 | active |
|---|---|---|---|---|
| gildong@gmail.com | 홍길동 | student | 싱어 | |
| teacher@gmail.com | 김교사 | teacher | | |

- MEMBERS에 등재되지 않았거나 `active`가 비활성인 이메일로 로그인하면 모든 요청이 `unauthorized`로 거부된다.
- **스코핑 주의**: v1에서는 teacher/admin 역할이면 활성 학생 **전원**의 기록을 조회할 수 있다(찬양팀은 단일 팀이라는 전제). 반별로 나뉘어 담당 학생만 보이는 구조가 아니다. 이 점을 교사들에게 미리 알려야 한다(`06-operations.md` 개인정보 항목 참고).

### RECORDS

1행(헤더)에 다음을 정확히 입력한다:

```
날짜 | email | 이름 | 말씀읽음 | 와닿은말씀 | 결단 | 수련회기도 | 기록시각 | 수정시각
```

- 이 탭은 앱이 자동으로 행을 추가/갱신한다. **데이터 행을 직접 입력하지 않는다.** 헤더 행에 "이 탭은 앱이 자동으로 기록합니다. 직접 편집 금지" 메모를 남겨두면 오조작을 막을 수 있다.
- 한 학생의 하루 기록은 `(날짜, email)` 조합으로 1행만 존재한다(upsert). 같은 날 여러 번 저장해도 행이 늘어나지 않고 기존 행이 갱신된다.
- 각 열의 의미:
  - `날짜`: `YYYY-MM-DD` 문자열(Asia/Seoul 기준).
  - `email`, `이름`: 서버가 로그인 토큰과 MEMBERS 조회 결과로 채운다. 사용자가 임의로 바꿀 수 없다.
  - `말씀읽음`, `수련회기도`: `TRUE`/`FALSE` 문자열.
  - `와닿은말씀`, `결단`: 자유 텍스트, 빈 값 허용.
  - `기록시각`: 해당 날짜 행이 최초 생성된 시각(ISO 문자열).
  - `수정시각`: 마지막으로 upsert된 시각(ISO 문자열).

## 시트 공유 권한 — 배포자만 접근하면 된다

이 앱의 GAS 웹앱은 "실행 계정: 나(배포자)"로 배포한다(`03-deploy-gas.md`의 `executeAs USER_DEPLOYING` 설정). 즉 학생·교사는 이 스프레드시트에 접근 권한이 전혀 없어도 앱을 정상적으로 사용할 수 있다 — 모든 시트 읽기/쓰기는 배포자 권한으로 GAS 서버 안에서만 일어난다.

- 이 시트를 학생이나 교사에게 공유할 필요가 없다. 공유하지 않는 편이 개인정보(와닿은말씀, 결단 등 신앙고백 텍스트) 노출 범위를 줄이는 데 유리하다.
- 배포자 본인 계정만 이 시트에 접근 가능한 상태(기본값)를 유지한다.
- 시트 백업이나 관리를 위해 다른 관리자와 공유해야 한다면, 편집자가 아닌 "뷰어" 권한을 우선 고려하고 최소한으로 유지한다.

## 출력
- 시트 ID 메모. 이후 `03-deploy-gas.md`의 Script Properties `SHEET_ID`에 입력한다.
- MEMBERS에 최소 1명 이상(본인 테스트용)의 학생/교사 행을 등록해 둔다.
